# قافلة · QAFILAH

**واحد منكم مو منكم.**

لعبة خداع جماعية بالعربي، تلعبونها وأنتم جالسين مع بعض، وكل واحد بجواله. الموقع يوزّع الأدوار، ويدير التصويت والمحطات، ويكشف كل شي في النهاية، وأنتم عليكم النقاش والشك والاتهامات.

قوانين اللعبة هي قوانين **The Resistance: Avalon** الرسمية بدون أي تعديل، بقصة وشخصيات عربية.

## القصة

قافلة تقطع الصحراء بالليل لين الواحة، وبين المسافرين غزاة متنكرين يبون يفشّلون الرحلة.

- **القافلة** تفوز إذا نجحت ٣ محطات من ٥، **وما** عرف وحشي مين الأحنف.
- **الغزاة** يفوزون إذا فشلت ٣ محطات، أو انرفض الفريق ٥ مرات ورا بعض، أو عرف وحشي الأحنف في النهاية.

| غازي | الغزاة | غازي عادي يعرف جماعته |

## التشغيل محليًا

تحتاج Node.js 18 أو أحدث.

```bash
npm install
npm start          # http://localhost:3000
npm test           # اختبارات القوانين + لعبة كاملة بسبعة لاعبين
```

عشان تجربونها من جوالاتكم على نفس الشبكة، افتحوا `http://<IP جهازك>:3000`.

## النشر

الموقع يحتاج سيرفر شغال، لأن اللعب مباشر عن طريق WebSockets، فما يشتغل على GitHub Pages.

**أسهل طريقة (مجانًا): Render**
1. ادخل [render.com](https://render.com) بحساب GitHub.
2. اختر **New → Blueprint** واختر هالريبو. ملف `render.yaml` فيه كل الإعدادات.
3. بعد دقائق يطلع لك رابط مثل `https://qafila.onrender.com`.

ملاحظة: الخطة المجانية في Render "تنام" إذا ما استخدمها أحد فترة، وأول فتح بعدها ياخذ حوالي نص دقيقة.

بدائل: Railway أو Fly.io. نفس الأوامر: `npm ci --omit=dev` للبناء، و`npm start` للتشغيل، والمنفذ من متغير `PORT`.

## قرارات مهمة

- **الأدوار ما تطلع من السيرفر.** كل جوال يوصله دوره ومعلوماته بس، فحتى لو أحد فتح أدوات المطور ما يشوف أدوار غيره.
- **شاشة المحطة نفسها للكل.** أهل القافلة يشوفون زر «خرّب» مثل الغزاة، ولو ضغطوه ينحسب «أوصل». كذا لو أحد لمح جوالك ما يعرف دورك.
- **إعادة الاتصال:** كل مقعد له معرّف عام ومفتاح سري محفوظ في متصفح صاحبه بس. لو قفلت الشاشة أو حدّثت الصفحة ترجع لنفس مكانك، ومحد يقدر ياخذ مقعدك (ويشوف دورك) لو عرف معرّفك.
- **إنهاء اللعبة:** لو أحد طلع نهائيًا واللعبة علقت، المضيف يقدر ينهيها ويرجعون لصالة الانتظار.
- **الغرف في الذاكرة:** لو انطفى السيرفر تروح الغرف. كافي للنسخة الأولى.
